# TTL注册表 v1.4

> 统一记录所有记忆文件的有效期定义和当前状态。
> TTL = Time To Live，文件自最后一次实质性更新后允许保持过期的最大天数。
> **TTL仅适用于"记忆信息"——有过期语义的数据。追加式记录（变更日志）和架构文档（五层记忆系统）不属于TTL管辖范围。**
> 本文件由唤醒记忆系统轻量模式读取，每次唤醒时输出TTL快报。

---

## 规则说明

| 状态 | 含义 |
|:--:|------|
| 🟢 | 距离上次实质性更新 < TTL |
| 🟡 | 距离上次实质性更新接近TTL（>80%） |
| 🔴 | 距离上次实质性更新 > TTL |
| ⚪ | 无TTL定义（永久保留） |

## 维护规则

1. 每次唤醒时读取本表，计算各文件距离上次实质性更新的天数，输出状态
2. 文件实质性更新后，同步修改本表中对应行的"上次实质性更新"日期
3. TTL阈值变化时，同步修改本表中对应行的TTL值
4. 新增/删除记忆文件时，在本表中增删对应行
5. **不属于TTL管辖的文件类型**：追加式记录（变更日志）、架构文档（五层记忆系统）、已有独立检测机制的文件（成长箱INDEX）——这些用联动更新规则而非TTL管理
