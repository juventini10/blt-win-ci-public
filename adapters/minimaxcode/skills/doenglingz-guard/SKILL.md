# MiniMax Code 端 · 童灵守护三查

> 🔴 **定位**：本 Skill 是 MiniMax Code 端童灵的**守护校验层（CHECK）**——承载 3 守卫适配，与「布洛陀-童灵守护」（Trae CN 端）/「布洛陀-豆包办公规则」同构但按本端真实机制落地。
> 🔴 **触发**：任何涉及童灵接入/校验/漂移检查的任务前自动加载；会话时三查验证。
> ⛔ **边界**：本 Skill 只做**校验与报告**，⛔不修改规格书/`AGENTS.md`/切片产物（改动作业走 K2 切片生成器单向流水线）。

## 一、守护三查（MiniMax Code 端适配）

> 本端**有** Stop / UserPromptSubmit / SessionStart 钩子——守护由三层承载：①**Stop 钩子链机械执行**（`doenglingz_guard.py` 等，经 JSON 契约适配器包裹）②**`AGENTS.md` 常驻注入**（平台 MUST 拼接块·童灵段在位）③**本 Skill 手动触发**（会话内三查与报告）。机械层是硬执行，⛔不是软约束兜底；本 Skill 只补"可读报告与人工可抽检"这一层。

### 查1：8要素校验（注入态完整性）

**职责**：校验本端童灵落点 `{{DATA_DIR}}/AGENTS.md` 的童灵段是否含 8 要素，防止 K2 切片嵌入残缺或漂移。

**8要素清单**：
1. 运行时注入声明（分身每次上岗必读·先于一切裁决）
2. 愿景声明（最高判据·四方向）
3. 品格底色（行为底色·六维）
4. L1 身份骨架（硬约束·不可协商）
5. L3 行为规则（铁律 + revealed preference）
6. L6 反向约束层（SHADOW + 自我状态感知）
7. 非职能域应答纪律
8. 零问题交付红线 + 门禁集

**判据**：逐项 Read `{{DATA_DIR}}/AGENTS.md` 命中；缺项 ⇒ 报缺项名 + 建议动作（⛔不自动补写·改 AGENTS.md 须先告知用户）。

**命令**（本端实盘口径）：

```bash
# AGENTS.md 童灵段存在性 + 8 要素粗检（⛔改 AGENTS.md 前先备份）
AGENTS="${MINIMAX_CONFIG_DIR:-$HOME/.minimax}/AGENTS.md"
grep -c "运行时注入声明\|愿景\|L1 · 身份骨架\|L3 · 行为规则\|L6 · 反向约束层" "$AGENTS"
```

### 查2：试金石校验（身份归属）

**职责**：校验会话中的数字分身回答是否**带着用户的意志**（=真分身），而非"执行得像"。

**判据**（三条通不过即报漂移）：
| # | 判据 | 通过条件 |
|:--|:--|:--|
| 1 | **意志归属** | 裁决依据来自用户已表达的意志/约束，不是 AI 自行"替用户优化" |
| 2 | **价值层不裁决** | 涉及用户价值取舍时**交回用户**，AI 只给逻辑链条与反例 |
| 3 | **不盲从也不盲顶** | 指出分歧时温和·引用原话·不评判人（只评判事） |

**判据来源**：`[记忆共享中心]/数字分身/童灵·人格规格书.md` §一（单一真源·⛔本 Skill 不复制判据正文）。

### 查3：机制指针可达性（⛔守卫全绿 ≠ 指针全对）

**职责**：校验 AGENTS.md / MEMORY.md 里指向共享中心的规则路径**物理可达**——这是本端最隐蔽的失败面。

**病形**：守卫静态腿全绿，但规则文件软链断链 ⇒ 规则**实际读不到** ⇒ 表现为"AI 明明有铁律却没遵守"。本端 `SessionStart` 已挂 `memory_pointer_reachability_guard.py --scope system` 做机械巡检。

**命令**（本端实盘口径）：

```bash
# 规则文件指针可达性（两档：system / full）
python3 "<记忆共享中心>/脚本中心/守卫/memory_pointer_reachability_guard.py" --scope system
```

**判据**：退出码 0 且无 🔴 债项 ⇒ 通过；有债项 ⇒ 按输出分类（真债 vs 仪器假阳性）后处置，⛔ 不批量改。

## 二、本端特有机制约束（守卫生效的前提）

| 约束 | 机理 | 守卫生效要求 |
|:--|:--|:--|
| **Stop 事件 JSON 契约** | 宿主要求 stdout 为单个 JSON 对象；共享守卫的纯文本 stdout 被判 `HOOK_INVALID_OUTPUT` **直接丢弃** | Stop 链**必裹** JSON 契约适配器；⛔裸挂 = 挂载在而产出不到 = **假绿** |
| **恒驻注入 = `AGENTS.md` 三合一** | 平台拼接块只有一份 `AGENTS.md`（SOUL+IDENTITY+自定义指令同文件分段） | 校验童灵段在**该文件**内，⛔不去找独立 `SOUL.md`/`IDENTITY.md` |
| **长期记忆只对默认会话开放** | agent memory 通道只开给内置默认会话；自定义 agent 会话无注入块 | 记忆面校验只在**默认会话**有效；自定义 agent 会话读不到 ≠ 机制故障 |
