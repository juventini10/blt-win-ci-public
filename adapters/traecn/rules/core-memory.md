## 硬路牌

- **知识调用开关**：接**写作/评估/工程/方法/健康**类任务时，✅DO 先跑 `env -u PYTHONHOME -u PYTHONPATH python3 [记忆共享中心]/脚本中心/search_kb.py "任务描述"` 检索沉淀知识，再开始正文——不依赖"记得"。
- **童灵上岗开关**：**显式调用童灵**（启动/唤醒/上岗/处理/评估/分析/判断/接手）或**命中童灵域切片触发词**时，✅DO 走本端 Skill `doenglingz-slice-nav` 执行上岗仪式（L3→L4→L5→L7 + 会话级 TSL 验证清单），守护三查走 `doenglingz-guard`——不依赖"记得"（**有 hook 端：W1 上岗注入由 UserPromptSubmit 钩子 `doenglingz_inject_prompt.py` 托底**；常驻层仍留触发定义）。域切片 L2-L5 按需加载、⛔不常驻（防 Lost in the Middle）。触发定义唯一真源=本条+Skill；Skill 只承载"怎么做"（细则）。
- **立场卡检索**：涉及**评估/决策/裁决/方案优化/愿景对齐/行为判断**时，✅DO 先跑同一条检索取 top-5 **立场卡锚点纳入决策依据**（数据源含立场卡库 `[日记仓库]/2-知识库/09-AI学习库/`；`--drill <路径>` 下钻全卡；纯代码/纯事实查询不触发）——动手前先翻立场库，不凭印象开口。立场卡由「好好学习」沉淀；装好语义增强（bge 模型）后同义问法也能命中（问"为什么总晚睡"能命中写"作息"的卡）。
- **Python 环境变量污染**：Trae 系工具 shell 注入 PYTHONHOME/PYTHONPATH，会污染所有 Python 脚本启动（报 `No module named 'encodings'`）。调用任何 Python 脚本前加 `env -u PYTHONHOME -u PYTHONPATH` 前缀。

- **产出签名**：每轮必标。无产出写 `[—— 本轮无实质产出 ——]`。完整格式见同上。
- **规则加载**：涉规则执行/签名判断/修改权限/冲突裁决 → MUST Read 铁律版头部「加载时机」索引表；改 Skill 先查架构规范再给方案。

## 平台机制事实（Trae CN）

| 维度 | 事实 |
|---|---|
| 注入形态 | user_rules 规则文件直落制（`~/.trae-cn/user_rules/` 全局 + `.trae/rules/` 项目级 + alwaysApply） |
| hooks | ✅ **标准 hook 端**：注册面 = `<配置根>/hooks.json`（⛔ 非 settings.json / 非 cli/config.json） |
| 调度 | 无内置定时器（`launchd_patrol: n_a`）·定时类能力由端自身事件面承载 |
| 守卫承载 | hook 事件面：UserPromptSubmit 逐轮注入（知识/铁律/路由）+ Stop 收口守卫链（未知未知路由·三层规则·卡片号·分身·TSL 收口） |
| 会话数据 | 转录由 `traecn_transcript_adapter.py` 解析；需转录的 Stop 守卫经其 `--run` 委派 |
| 未知未知路由 | Stop 钩子 `route_unknown_unknown.py` 自动路由（对话内【🕳️】段仍可显式 Write 悬置区.md，二者去重） |
